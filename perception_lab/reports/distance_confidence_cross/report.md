## 统计口径

- 统计 1,910 条原始失败记录，排除 34 条同 ID 间隔恢复（gap_recovery）；不是归并后的事件数量，也不是去重目标数。同一目标跨帧、跨模块或不同失败类型可贡献多条记录。
- 包括 FP 1,599、FN 114、连续 ID 切换 46、中断后 ID 变化 38、中心误差超过 1 m 的记录 113。
- 距离为目标中心相对自车的水平 XY 距离，与工作台距离筛选一致。FP 使用预测中心；FN、身份变化、中心误差案例使用原案例的 GT 中心。
- 置信度沿用已绑定原始案例 SHA256 的分数表：FP 为当前预测分数，中心误差为匹配框分数，ID 变化为当前新 ID 的预测分数。FN 没有匹配预测，单列 N/A，不把它当成零分或低分预测。
- 基线评估 score ≥ 0.25、匹配距离 < 2 m；本次仅分桶统计现有失败记录，不改变阈值重新评估。采用原始标签，未应用人工复核修正。
- 距离分档左闭右开；最后一档 ≥40 m。置信度分档左闭右开，最后一档包含 1.00。

20–40 m 共 1,225 条，占 64.1%；0.25–<0.40 共 1,083 条，占全部失败记录的 56.7%。这些是失败数量分布，不是各分档失败率，不能据此直接判断远近距离的模型准确率。
