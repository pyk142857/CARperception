# 驾驶相关感知失败候选：距离与置信度分布

日期：2026-09-30。数据：scene-0061，39 帧，CenterPoint 与当前 max_age=3 跟踪基线；检测和跟踪合并，原始标签，排除同 ID 间隔恢复，保留 1,910 条失败记录。

## 解释范围

本项目没有规划控制或真实驾驶动作验证。这些是可能影响下游判断的感知失败候选，不是已确认导致驾驶异常的事件。漏检可能遗漏让行/避碰对象，误检可能引入多余响应，中心误差可能影响间距估计，ID 变化可能打断运动历史。这里没有为它们设定已验证的风险等级，也没有判定实际应采取的驾驶动作。

“近前方”沿用已有空间诊断：自车坐标 0≤x≤30 m、|y|≤3 m。它只是复核用矩形，不代表实际车道、行驶路径或安全距离。其他区域仍可能与横穿、转弯、变道有关。

距离为水平 XY 距离；FP 使用预测中心，其余使用原案例 GT 中心。ID 案例置信度为当前新 ID 的预测分数；漏检无对应预测分数。使用固定 score≥0.25、匹配距离<2 m 的原评估，不重新设置阈值。不包括 MapTR、分割、信号灯等输出的失败。

## 优先复核实例

近前方漏检共 7 条（检测 4、跟踪 3），对应 3 个真实目标、4 次目标观测。检测案例：

| 案例 | 类别 | 帧 | 位置 | 置信度 |
|---|---|---:|---|---|
| case_00341 | 行人 | 14 | 前方约19.6 m、右侧1.7 m | 无 |
| case_00542 | 交通锥 | 18 | 前方约22.3 m、右侧0.9 m | 无 |
| case_01080 | 自行车 | 37 | 前方约16.4 m、左侧2.2 m | 无 |
| case_01126 | 同一自行车 | 38 | 前方约15.4 m、左侧1.1 m | 无 |

可在本地失败工作台搜索上述案例 ID，核对图像、点云和连续帧。

全部区域中，41/46 条连续 ID 切换在 20–40 m；置信度≥0.6 的连续 ID 切换为22条。误检中置信度≥0.8有10条。预测分数不是驾驶风险分数，不能以高分判断轨迹可靠，或以低分排除驾驶相关性。
